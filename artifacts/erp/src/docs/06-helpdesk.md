# 客服中心

處理客戶問題回報（客訴）的完整流程。

## 整體流程

```
接到客訴 → 建立工單 → 依 SLA 時限處理 → 記錄解決方式 → 結案
                ↘ 常見問題整理進知識庫
```

## 客訴工單（客服中心 → 客訴工單）

1. 接到客戶反映後，按「新增工單」：選擇客戶、問題分類、優先等級、描述問題。
2. 指派承辦人，工單狀態依處理進度更新：**開啟 → 處理中 → 已解決 → 結案**。
3. 每次與客戶的往來、處理動作都記錄在工單裡，方便交接與追蹤。
4. 可使用「AI 客訴分類」自動判斷問題分類與優先度。

## SLA 與分類（客服中心 → SLA 與分類）

- **SLA（服務水準）**：設定各優先等級的「應回應時間」與「應解決時間」，逾期系統會標示提醒。
- **分類**：維護問題類型（例如：課程問題、退費、系統操作），方便統計常見問題。

## 知識庫（客服中心 → 知識庫）

- 將常見問題的標準處理方式寫成知識庫文章，客服人員處理工單時可直接查詢引用。
- 建議每解決一類新問題，就順手補一篇知識庫，減少重複摸索。

> 💡 這裡的「知識庫」是**客服處理經驗**的資料庫；您現在看的「使用說明」則是**系統操作**的說明文件，兩者用途不同。
