# 報表中心

各類財務與營運報表，多數支援期間篩選與匯出。

## 財務報表

| 報表 | 用途 |
| --- | --- |
| 損益表 | 看某期間賺或賠：收入 − 成本 − 費用 |
| 資產負債表 | 看某時點的財務狀況：資產、負債、權益 |
| 現金流量表 | 看現金實際進出（營運/投資/籌資） |
| 試算表 | 檢查全部科目借貸是否平衡 |
| 總分類帳 | 查單一科目的每筆分錄明細 |

## 營運報表

| 報表 | 用途 |
| --- | --- |
| 應收帳齡 | 哪些客戶欠款、欠多久（催收依據） |
| 應付帳齡 | 欠供應商多少、何時該付 |
| 銷售分析 | 按客戶/品項/期間分析銷售 |
| 採購分析 | 按供應商/品項分析採購 |
| 毛利分析 | 各品項/訂單的毛利率 |
| 庫存報表 | 各品項庫存數量與價值（移動平均成本） |
| 預算 vs 實際 | 比較各科目預算與實際數 |

## 部門 / 專案損益（BU 報表）

- 報表可按「部門」或「專案」切分，看各業務單位的獨立損益。
- 歸屬規則：單據表頭選的部門優先；內部轉撥不計入損益。

## 使用技巧

- 報表右上多有「匯出」按鈕，可下載 Excel / PDF。
- 數字有疑問時，從報表點擊科目可下鑽到「總分類帳」看每一筆來源分錄。
- 期間別報表建議關帳後再看，數字才是最終版。
