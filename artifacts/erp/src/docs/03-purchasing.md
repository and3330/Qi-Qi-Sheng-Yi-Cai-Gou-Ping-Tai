# 採購管理

處理向供應商下單、收貨、對帳付款的流程。

## 整體流程

```
採購訂單 → 進貨單 → 採購發票 → 付款單
            ↘ 採購退貨（如需退回）
```

## 供應商（採購 → 供應商）

- 維護供應商名稱、統編、聯絡資訊、付款條件。

## 採購訂單（採購 → 採購訂單）

1. 按「新增採購訂單」，選擇供應商、品項、數量與單價。
2. 確認後即可通知供應商出貨，並等待收貨。

## 進貨單（採購 → 進貨單）

1. 貨到後，從採購訂單建立進貨單，填寫實際收到的數量（支援分批進貨）。
2. **進貨單「確認」後庫存才會增加**。
3. 虛擬服務類品項不影響庫存。

## 採購發票（採購 → 採購發票）

1. 收到供應商發票後，從進貨單轉開採購發票。
2. 確認後自動產生會計分錄（借進貨/費用 + 進項稅額 / 貸應付帳款）。
3. 付款後建立「付款單」沖銷，發票的已付金額自動更新。

## 採購退貨（採購 → 採購退貨)

1. 按「新增退貨單」，選擇原進貨單與退回品項數量。
2. **確認退貨**後系統自動：
   - 扣回庫存
   - 建立「反轉進貨單」與「扣項單」
   - 自動沖回成本分錄
3. 退貨做錯可按「取消退貨」，全部自動復原。
4. 扣項單已有付款沖抵時，需先處理完才能取消。

## 常見問題

- **收到的貨比訂單少？** 進貨單填實際數量即可，之後可再建第二張進貨單補收。
- **發票金額與訂單不同？** 以採購發票上的實際金額為準入帳，必要時修改發票明細。
