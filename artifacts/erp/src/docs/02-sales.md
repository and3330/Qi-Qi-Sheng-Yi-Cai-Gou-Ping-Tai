# 銷售管理

處理從報價、接單、出貨到開發票的完整銷售流程。

## 整體流程

```
報價單 → 銷售訂單 → 送貨單 → 銷售發票 → 收款單
                     ↘ 銷售退貨（如需退回）
```

每一步都可以從上一步「一鍵轉單」，資料自動帶入，不用重打。

## 客戶管理（銷售 → 客戶）

- 建立客戶基本資料：名稱、統編、聯絡方式、付款條件。
- 客戶資料會被報價單、訂單、發票共用，維護一次即可。

## 報價單（銷售 → 報價單）

1. 按「新增報價單」，選擇客戶、加入品項與數量、單價。
2. 可以套用「報價模板」快速帶入常用內容，或用「價目表」自動帶價。
3. 報價單可列印 / 匯出 PDF 給客戶。
4. 客戶同意後，在報價單上按「轉為銷售訂單」。

## 銷售訂單（銷售 → 銷售訂單）

1. 從報價單轉入，或直接新增。也可用「快速錄單」以表格方式大量輸入。
2. 確認後訂單狀態會隨出貨進度自動變化：
   - **待出貨（To Deliver）**：尚未出貨或部分出貨
   - **已完成（Completed）**：全部出貨且款項處理完畢
3. 常用的訂單內容可存成「訂單模板」重複使用。

## 送貨單（銷售 → 送貨單）

1. 從銷售訂單按「建立送貨單」，選擇本次出貨數量（支援分批出貨）。
2. **送貨單「確認」後才會扣庫存**，並回頭更新訂單的出貨狀態。
3. 虛擬服務類品項（如課程、服務費）不會扣庫存。

## 銷售發票（銷售 → 銷售發票）

1. 從送貨單或訂單轉開發票，系統自動計算營業稅。
2. 發票確認後會**自動產生會計分錄**（借應收帳款 / 貸銷貨收入），不需手動做帳。
3. 支援電子發票（ECPay）開立。
4. 收到貨款後建立「收款單」沖銷發票，發票的已收金額會自動更新。

## 銷售退貨（銷售 → 銷售退貨）

1. 按「新增退貨單」，選擇原送貨單與退回的品項數量。
2. **確認退貨**後系統會自動：
   - 把庫存加回來
   - 建立「反轉送貨單」與「折讓單」
   - 自動沖回營收分錄
   - 更新原訂單狀態（例如從「已完成」退回「待出貨」）
3. 如果退貨做錯了，可按「取消退貨」，以上動作會全部自動復原。
4. 折讓單若已有收付紀錄，需先處理完才能取消退貨。

## 常見問題

- **訂單一直不會變「已完成」？** 確認所有送貨單與發票都已確認、款項已收齊。
- **想修改已確認的單據？** 已確認單據不能直接改，請先取消再重新建立，帳務才會正確。
