# 系統管理與權限

（此區多數功能僅系統管理員可見）

## 使用者與角色

- **使用者管理**：建立登入帳號、指派角色、重設密碼。
- 常見角色權限：

| 角色 | 權限範圍 |
| --- | --- |
| 超級管理員 | 全部功能 + 系統設定 |
| 管理員 | 日常營運全模組 |
| 財務 | 會計、報表、收付款 |
| 人資 | 員工、出勤、薪資 |
| 業務 | 銷售相關模組 |
| 一般員工 | 只有打卡、請假、個人資料、AI 助理 |

## 簽核流程（系統 → 審核流程）

- 可設定哪些單據（例如付款申請、請假）需要簽核、由誰簽核。
- 待簽核項目會出現在簽核人的通知中心。

## 通知中心

- 系統通知包含：待簽核、庫存不足、合約到期、SLA 逾期等。
- 點擊通知直接前往對應頁面處理。

## API 金鑰

- 供外部系統（例如官網、電商）串接 ERP 資料使用。
- 金鑰只在建立時顯示一次，請妥善保存；不用的金鑰請立即停用。

## 匯入 / 匯出

- 支援 Excel/CSV 批次匯入客戶、品項、期初資料等；匯入前請先下載範本按格式填寫。

## 資料備份

- 管理員可在備份頁面手動下載資料備份。

## 管理工具

- **補建歷史發票分錄**：一鍵為過去缺分錄的已確認發票補建會計分錄（部署新版後或匯入歷史資料後使用）。
- **示範模式**：展示用環境的資料重置功能（正式環境不會啟用）。

## 安全建議

- 每位使用者用自己的帳號，不要共用。
- 員工離職請立即停用帳號。
- 定期檢查 API 金鑰清單，移除不再使用的金鑰。
