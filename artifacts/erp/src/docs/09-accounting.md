# 財務會計

日常帳務、發票稅務與收付款管理。

## 核心觀念：大部分分錄是自動的

銷售發票、採購發票、退貨折讓、薪資發放等單據「確認」時，系統會**自動產生會計分錄**，日常不需要手工做帳；手工分錄只用於例外狀況（開帳、調整、結轉）。

## 會計科目（會計 → 會計科目）

- 樹狀科目表，分錄只能掛在**最底層（葉節點）**科目。
- 新增科目時注意掛對上層科目與大類（資產/負債/權益/收入/費用），報表才會正確。

## 日記帳（會計 → 日記帳）

- 檢視所有分錄（自動 + 手工），可按日期、科目、來源篩選。
- 手工分錄：借貸金額必須相等才能儲存。

## 發票與營業稅

```
銷項：銷售發票確認 → 自動分錄 → 營業稅申報表彙總銷項稅額
進項：採購發票/請款單 → 自動分錄 → 營業稅申報表彙總進項稅額
```

- **發票**（會計 → 發票）：集中管理所有銷項/進項發票，支援 ECPay 電子發票開立與作廢。
- **營業稅申報**（會計 → 營業稅申報）：選擇期間，系統自動彙總銷項、進項稅額並計算應納/留抵稅額，作為每期 401 申報依據。

## 收付款

- **收款單**：收到客戶款項時建立，選擇要沖銷的發票，發票「已收金額」自動更新，訂單狀態也會連動。
- **付款單**：支付供應商款項，沖銷採購發票。
- **請款單**：員工代墊費用或廠商請款的內部申請，核准後產生費用分錄並可轉付款。
- **付款申請**：需要簽核的對外付款流程。
- **銀行對帳**：上傳銀行對帳單（CSV），系統自動比對帳上收付款紀錄，找出未達帳項目。

## 關帳（鎖帳）

- 在會計設定中設定「鎖帳日」後，該日期（含）以前的期間**不能再新增、修改或取消**會影響帳務的單據，防止已申報期間被改動。
- 需要修改已鎖帳期間的資料時，請管理員暫時調整鎖帳日。

## 常見問題

- **報表金額和發票對不起來？** 檢查發票是否都已「確認」（草稿不入帳），或使用管理頁的「補建歷史發票分錄」功能。
- **取消單據被擋？** 多半是該單據日期落在已鎖帳期間，或關聯的折讓單已有收付紀錄。
