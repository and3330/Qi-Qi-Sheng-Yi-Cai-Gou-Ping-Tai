# 快速上手

歡迎使用七期生醫 ERP 系統。本頁介紹系統的基本操作方式與各區域功能。

## 登入與帳號

- 使用管理員提供的帳號密碼登入系統。
- 登入後右上角會顯示您的名字，點擊可以登出。
- 不同角色（管理員、財務、人資、業務、一般員工）看到的選單與功能不同，看不到某功能通常代表您沒有該權限，可洽系統管理員。

## 畫面配置

- **左側選單**（電腦版）：所有功能模組依「營運管理、人事管理、財務管理、系統管理」分組，點擊群組可展開子功能。
- **底部導覽列**（手機版）：常用功能放在底部，其餘功能收在「更多」選單中。
- **頂部工具列**：
  - 🔍 **全域搜尋**：點擊搜尋框或按 `⌘K`（Windows 為 `Ctrl+K`），可一次搜尋訂單、客戶、發票、員工等資料。
  - 🔔 **通知中心**：顯示待簽核、庫存不足等系統通知，點擊可直接前往相關頁面。
  - ❓ **使用說明**：也就是本查詢中心，隨時可回來查功能怎麼用。

## 常見操作模式

系統中大部分單據（訂單、發票、請假單…）都遵循相同的操作邏輯：

1. **建立（草稿 Draft）**：按「新增」填寫資料後儲存，此時單據還沒有生效，可以自由修改或刪除。
2. **確認（已送出 Submitted）**：確認資料無誤後送出，此時才會真正影響庫存、帳務或進入簽核流程。
3. **完成 / 取消**：流程走完會標記完成；送出後發現錯誤，多數單據可以「取消」，系統會自動回沖相關的庫存與帳務。

> 💡 **原則：草稿可以隨便改，送出後要用「取消」而不是直接刪除**，這樣帳才會平。

## 單據狀態說明

| 狀態 | 意義 |
| --- | --- |
| Draft（草稿） | 尚未生效，可修改、可刪除 |
| Submitted（已送出/已確認） | 已生效，影響庫存或帳務 |
| Completed（已完成） | 流程結束 |
| Cancelled（已取消） | 已作廢，相關影響已自動回沖 |

## 遇到問題怎麼辦

1. 先在本查詢中心搜尋關鍵字（例如「退貨」、「薪資」）。
2. 使用「AI 查詢助理」用白話文問系統資料（例如「這個月營收多少？」）。
3. 仍無法解決時，聯繫系統管理員。
