# 人事管理

涵蓋員工資料、出勤打卡、請假與薪資。

## 組織與員工

- **部門管理**：建立公司部門樹狀結構，設定主管。
- **員工**：維護員工基本資料、到職日、部門、職稱，以及**薪資設定**（底薪、津貼、勞健保投保級距）。
  - ⚠️ 薪資設定沒填的員工，產生薪資單時金額會不正確，請先補齊。
- **老師管理**：外部授課老師的資料與課酬管理。

## 出勤與打卡

```
班制設定 → 打卡地點設定 → 員工每日打卡 → 出勤紀錄 → 月底串接薪資
```

- **打卡系統**：員工上下班用手機打卡，系統會檢查 GPS 是否在允許的打卡地點範圍內。
- **打卡地點**：設定允許打卡的地點座標與範圍（公尺）。
- **班制設定**：定義上下班時間、休息時間，遲到早退依此判斷。
- **出勤紀錄**：人資檢視全員出勤，處理補打卡、異常出勤。

## 請假管理

```
員工送出請假單 → 主管審核（核准/駁回） → 出勤與薪資自動反映
```

1. 員工選擇假別（特休、病假、事假…）、日期與時數，送出申請。
2. 主管在同頁面審核。
3. 核准後的請假會自動反映在出勤與薪資計算。

## 薪資與保險

```
薪資設定 → 每月薪資計算 → 產生薪資單(草稿) → 確認發放 → 自動產生薪資分錄
```

- **薪資計算**：選擇月份，系統依出勤、請假、加班與薪資設定自動試算全員薪資，可批次產生薪資單。
- **薪資單**：逐筆檢查草稿薪資單，確認無誤後「確認發放」，系統自動產生薪資費用分錄；薪資單可列印/下載給員工。
- **投保級距**：維護勞保、健保級距表，計算時自動套用。

## 一般員工看到什麼？

一般員工角色登入後只能使用：打卡、請假、個人資料（含個人薪資單）與 AI 查詢助理，看不到其他人的資料。
