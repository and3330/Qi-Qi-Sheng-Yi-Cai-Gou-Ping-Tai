# 專案與合約

## 專案管理（專案 → 所有專案）

- 專案用來歸集特定業務的收入與支出（例如某課程專案、某活動）。
- 單據（訂單、發票、請款單）上可以選擇所屬「專案」與「部門」，報表就能按專案 / 部門看損益。
- **歸屬規則**：單據表頭選的部門優先於專案預設部門。

### 任務（專案 → 任務）

- 在專案下建立待辦任務，指派負責人與到期日，追蹤執行進度。

### 專屬看板

- **課程專案（noncodingai）** 與 **CM生活+ 電商**：與外部系統自動同步的專屬營運看板，資料由系統排程自動更新。

## 合約管理（合約 → 合約）

1. 建立合約：填寫合約對象、金額、起訖日期、付款節點。
2. 上傳合約掃描檔留存。
3. 合約到期前系統會提醒續約。

## 流程

```
建立專案 → 單據掛上專案 → 專案損益報表
建立合約 → 追蹤付款節點 → 到期提醒續約
```
