# 資產、製造與品質

## 資產管理

```
購入資產 → 登記資產 → 每月折舊 → 維護保養 → 報廢/處分
```

- **資產登記冊**：登記公司固定資產（設備、電腦、家具），記錄購入日期、金額、使用年限。
- **資產類別**：設定各類資產的折舊方法與年限。
- **折舊排程**：系統依設定自動計算每期折舊金額，並可產生折舊分錄。
- **資產維護**：記錄維修保養歷史與費用。

## 製造管理

```
物料清單(BOM) → 工單 → 領料 → 生產(作業卡) → 完工入庫
```

- **物料清單（BOM）**：定義一個成品需要哪些材料與數量。
- **工單**：要生產時建立工單，指定成品、數量與 BOM。
  - **領料**：從倉庫領出材料，庫存減少（虛擬材料不動庫存）。
  - **完工**：成品入庫，庫存增加（虛擬成品不入庫）。
- **工作站 / 作業卡**：記錄各工序在哪個工作站執行、工時多少。
- **生產計畫**：檢視整體生產排程與產能。

## 品質管理

```
檢驗範本 → 品質檢驗 → 不合格 → 不符合報告(NCR) → CAPA 改善
```

- **檢驗範本**：預先定義檢驗項目與標準（例如進貨檢驗、出貨檢驗清單）。
- **品質檢驗**：對進貨、生產或出貨執行檢驗並記錄結果。
- **不符合報告（NCR）**：檢驗不合格時開立，記錄問題與處置方式（退貨、重工、特採）。
- **CAPA（矯正預防措施）**：針對重複性問題制定改善計畫並追蹤成效。
