# 庫存管理

管理品項主檔、倉庫與庫存數量。

## 品項（庫存 → 品項）

- 每個可以買賣或領用的東西都是一個「品項」，需設定名稱、編號、分類、單位與售價/成本。
- **虛擬服務**：課程、服務費、授權等「沒有實體庫存」的品項請勾選「虛擬服務」，這類品項出貨/進貨都不會影響庫存數字。
  - 品項如果已有庫存或未完成的工單，需先處理完才能切換為虛擬服務。
- 可設定「安全庫存量」，低於時系統會發出庫存不足通知。

## 品項分類與類型

- 用來將品項分組，方便搜尋與報表統計（例如：教材、設備、服務）。

## 倉庫（庫存 → 倉庫）

- 可建立多個倉庫（例如：總倉、門市倉）。
- 單據上可指定出入庫的倉庫。

## 庫存異動（庫存 → 庫存異動）

- 這裡記錄所有庫存增減的歷史：進貨、出貨、退貨、工單領料、盤點調整。
- 如需手動調整庫存（盤點盈虧），在此建立調整單並註明原因。

## 庫存數字怎麼變動？

| 動作 | 庫存變化 | 發生時機 |
| --- | --- | --- |
| 進貨單確認 | ➕ 增加 | 採購收貨 |
| 送貨單確認 | ➖ 減少 | 銷售出貨 |
| 銷售退貨確認 | ➕ 增加 | 客戶退回 |
| 採購退貨確認 | ➖ 減少 | 退回供應商 |
| 工單領料 | ➖ 減少 | 生產領用 |
| 工單完工 | ➕ 增加 | 成品入庫 |
| 手動調整 | ➕/➖ | 盤點 |

> 💡 庫存只會因「已確認」的單據變動，草稿不影響庫存。

## 常見問題

- **庫存數字不對？** 到「庫存異動」查該品項的完整歷史，找出是哪張單據造成的。
- **出貨時提示庫存不足？** 先確認進貨單是否已「確認」，或檢查是否選錯倉庫。
