# Linktree 個人連結頁模組 (Linktree Module)

類似 Linktree 的個人連結頁功能，每位用戶可建立自己的連結頁面，支援自訂主題和外觀。

## 檔案清單

| 檔案 | 說明 |
|------|------|
| `schema.sql` | 資料庫建表（user_links + user_linktree_settings） |
| `linktree-routes.ts` | Express 路由：連結 CRUD、外觀設定、公開頁面 |
| `LinktreePage.tsx` | React 元件：公開展示頁面 |

## 安裝步驟

1. 執行 `schema.sql` 建立資料表
2. 將 `linktree-routes.ts` 引入 Express 並注冊路由：
   ```typescript
   import { createLinktreeRoutes } from './linktree-routes';
   app.use(createLinktreeRoutes({ db, userLinks, userLinktreeSettings, users, eq, and, asc }));
   ```
3. 將 `LinktreePage.tsx` 複製到前端頁面目錄，用於顯示公開連結頁

## API 路由

| 方法 | 路徑 | 說明 | 權限 |
|------|------|------|------|
| GET | `/api/linktree/links` | 取得我的連結列表 | 登入 |
| POST | `/api/linktree/links` | 新增連結 | 登入 |
| PATCH | `/api/linktree/links/:id` | 更新連結 | 登入 |
| DELETE | `/api/linktree/links/:id` | 刪除連結 | 登入 |
| GET | `/api/linktree/settings` | 取得外觀設定 | 登入 |
| PUT | `/api/linktree/settings` | 更新外觀設定 | 登入 |
| GET | `/api/linktree/public/:userId` | 公開頁面資料 | 公開 |

## 自訂項目

| 項目 | 預設值 | 說明 |
|------|--------|------|
| 主題 | default | 可選：default, dark, gradient, pastel |
| 按鈕樣式 | rounded | 可選：rounded, pill, square, outline |
| 背景色 | — | `backgroundColor` 自訂色碼 |
| 按鈕色 | — | `buttonColor` 自訂色碼 |
| 顯示頭像 | true | `showAvatar` 開關 |
| 自訂標題 | 用戶名稱 | `customTitle` 欄位 |

## npm 依賴

後端：`express`, `drizzle-orm`
前端：`lucide-react`, shadcn/ui（Avatar, Button）
